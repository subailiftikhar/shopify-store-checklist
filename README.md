# Shopify Store Checklist 🛍️

A free, practical checklist for **launching, speeding up and improving conversions** on a Shopify store. It's built from managing 100+ e-commerce stores for brands in the US, UK, Canada and Europe.

Use it before you launch, before you spend money on ads, and before every big sale (Black Friday, Cyber Monday, holidays).

## 1. Pre-launch setup

- [ ] Custom domain connected and set as primary (redirect `*.myshopify.com`)
- [ ] Professional email on your domain (support@, hello@)
- [ ] Payments: Shopify Payments + PayPal + Shop Pay enabled; test order placed and refunded
- [ ] Store currency, markets and taxes set for every country you sell to
- [ ] Shipping zones and rates tested with a real address in each market
- [ ] Policies published: Refund, Privacy, Terms of Service, Shipping, Contact
- [ ] Favicon, logo and social share image (1200×630) uploaded
- [ ] Password page removed, and a test order placed from a phone on mobile data
- [ ] Contact page with email, response time and (optional) WhatsApp

## 2. Product page conversion (CRO)

- [ ] **Title** says what it is, in the words buyers search for (not just a brand name)
- [ ] **5+ images** or a short video: white background, lifestyle shot, scale or size shot, close-up
- [ ] **Price, shipping cost and delivery time** visible before the Add to Cart button
- [ ] **3–5 benefit bullets** above the fold. Benefits first, specs below
- [ ] **Reviews with photos** near the Add to Cart button
- [ ] Clear **variant selector**; sold-out variants are crossed out, not hidden
- [ ] **Sticky Add to Cart** on mobile
- [ ] Size guide / FAQ / returns in collapsible tabs
- [ ] Real urgency only (low stock or a dated sale). No fake countdown timers
- [ ] Cross-sell or "frequently bought together" on the product page or cart

## 3. Store speed

- [ ] Use a modern, Online Store 2.0 theme (Dawn-based or a well-coded premium theme)
- [ ] Remove apps you don't use, **and** delete the code they leave behind in `theme.liquid`
- [ ] Compress images; upload at the size you display (≤ 2048px wide for most)
- [ ] Limit homepage sliders and autoplay videos above the fold
- [ ] Load third-party scripts (chat, reviews, pop-ups) after page load where possible
- [ ] Check Core Web Vitals in Shopify **Online Store → Themes → Web performance** and in PageSpeed Insights (mobile)
- [ ] Fonts: max 2 font families, use system fonts where you can

## 4. Shopify SEO

- [ ] Unique **SEO title** (≤ 60 chars) and **meta description** (≤ 155 chars) for home, collections and top products
- [ ] Collection pages have 100–300 words of helpful copy (top or bottom)
- [ ] Product descriptions are original, not copied from the supplier
- [ ] Image **alt text** on every product image
- [ ] Clean URLs (`/products/gold-moon-necklace`, not `/products/copy-of-item-12`)
- [ ] 301 redirects for deleted products and changed URLs
- [ ] Sitemap (`/sitemap.xml`) submitted in Google Search Console
- [ ] A blog that answers buyer questions ("how to choose…", "X vs Y")

## 5. Tracking: Meta Pixel, Conversions API and GA4

- [ ] Meta Pixel **and** Conversions API connected (Shopify's Facebook & Instagram channel, data sharing set to *Maximum*)
- [ ] Domain verified in Meta Business Manager
- [ ] Events firing: ViewContent → AddToCart → InitiateCheckout → Purchase (with value and currency); check in Events Manager → Test Events
- [ ] Google Analytics 4 connected via the Google & YouTube channel
- [ ] Google Merchant Center product feed approved (for Shopping / Performance Max)
- [ ] UTM parameters on every ad, email and social link

## 6. Checkout and trust

- [ ] Accelerated checkouts on (Shop Pay, Apple Pay, Google Pay, PayPal)
- [ ] Guest checkout allowed
- [ ] Trust info near the button: returns window, secure payment, delivery estimate
- [ ] Abandoned checkout email + SMS flow (3 messages over 24–72 hours)
- [ ] Post-purchase email with tracking link and a review request 7–14 days later
- [ ] Support reply time under 24 hours (under 1 hour is a real conversion edge)

## 7. Marketplaces: Amazon, eBay, Walmart and TikTok Shop

- [ ] Inventory synced from Shopify (connector app or multichannel tool); no manual CSVs
- [ ] Keep a 1–2 unit **buffer** on marketplaces for fast sellers to avoid oversells
- [ ] Marketplace-specific titles (eBay: up to 80 chars; Amazon: brand + key features)
- [ ] All **item specifics / attributes** filled (brand, MPN/GTIN, size, colour, material)
- [ ] Shipping and return policies mapped to each marketplace's business policies
- [ ] Account health checked weekly (late shipment, cancellation and defect rates)

## 8. Black Friday / BFCM prep

- [ ] Offer decided and tested 3–4 weeks before (discount, bundle or gift with purchase)
- [ ] Theme speed-tested and checkout tested on mobile
- [ ] Email and SMS flows written and scheduled; list cleaned
- [ ] Ad accounts warmed up early. Don't launch brand-new campaigns on the day
- [ ] Stock levels confirmed and synced across Shopify and marketplaces
- [ ] Support team / canned replies ready for the rush week
